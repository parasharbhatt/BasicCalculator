
# Basic Calculator

A desktop calculator built with Python and the Tkinter standard library.

## Features

- Addition, subtraction, multiplication, and division
- Power (`x^y`) and square (`x^2`) operations
- Decimal, percentage, sign toggle, backspace, and clear controls
- Keyboard support for digits, operators, Enter, Backspace, and Escape
- Division-by-zero and overflow errors shown clearly in the display
- Responsive, neatly styled Tkinter interface

## Requirements

- Python 3.8 or newer
- Tkinter (included with the standard Python installation on Windows)

## Run

From the project directory:

```powershell
python Basic_Calculator.py
```

## Controls

| Action | Control |
| --- | --- |
| Enter digits | Number buttons or keyboard |
| Operation | `+`, `-`, `*`, `/`, or `^` |
| Calculate | `=` or Enter |
| Delete last digit | Backspace |
| Clear all | `C`, Delete, or Escape |
| Toggle sign | `+/-` |
| Percentage | `%` |
